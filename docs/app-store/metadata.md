## Description

xlatch connects your iPhone to tools you run on your own computers.

Pair a server with a QR code, then send links, text, images, audio, documents, and other files from the iOS share sheet. The actions in xlatch come from your server, so the same app can save something for later, transcribe audio, pass context to an agent session, start media jobs, or invoke a workflow you created.

You stay in control:

• Direct connections to servers you choose
• HTTPS certificate pinning established during pairing
• Device-specific cryptographic credentials
• Optional Face ID approval for sensitive changes
• Per-device access grants and revocation
• Durable queued transfers and job results
• Multiple servers and customizable action order and icons

A running xlatch server is required. xlatch does not provide a hosted execution service.

## Review notes

xlatch requires a separately installed, self-hosted xlatch server. The reviewer account does not require a username or password.

Provide Apple review with:

1. A temporary review server reachable from the public internet or an included demonstration mode.
2. A pairing QR code or text pairing payload that remains valid for the review window.
3. One or more harmless actions, such as “Save for later” and “Echo shared content.”
4. Exact steps: launch xlatch, scan or paste the pairing code, open Safari, share a page to xlatch, select the Echo action, and inspect the resulting job in Activity.

Explain that production users normally pair servers on a local network or private overlay network, while the supplied review server is available for App Review.
