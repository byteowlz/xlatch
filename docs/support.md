# xlatch Support

xlatch is a client for self-hosted xlatch servers. Start with the [README](../README.md) for installation, pairing, and service commands. The [testing guide](testing.md) covers the iOS pairing and share-sheet flow.

Before reporting a problem, collect the output of these commands without posting pairing codes, device credentials, or private shared content:

```sh
xlatch service status
xlatch devices
xlatch list
xlatch jobs
```

Open a support request in [GitHub Issues](https://github.com/byteowlz/xlatch/issues). Include the xlatch version, host operating system, iOS version, the failed action, and the exact non-sensitive error message.
